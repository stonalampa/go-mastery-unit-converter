# Unit Converter

A small web app that converts a value from one unit of measurement to another, one category per page.

## Language

**Category**:
A family of units that can be converted into each other: length, weight or temperature.
_Avoid_: Type, measurement, kind, dimension

**Unit**:
One named measure within a category, such as meter, pound or Kelvin; it has a full name and a symbol.
_Avoid_: Measure, scale

**Conversion**:
Turning a value expressed in one unit into the equal value in another unit of the same category.
_Avoid_: Calculation, transform, translation
